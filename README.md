#QA Automation Platform

## Project overview

This is a Django-based QA Automation Platform Project.
The goal of this platform is to provide role-based access for users such as Admin, manager, Tester and later support QA-related activities.

Current implementation includes:

- User login
- Role-based access
- JWT Authentication
- Protected API endpoint
-Token expiry testing

----

## Technologies used

-Python
-Django
-PostgresSQL
